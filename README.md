# studio_wolf

撮影スタジオ狼の公式サイト

## 概要

コスプレイヤーによる、コスプレイヤーのための撮影スタジオ「撮影スタジオ狼」の公式ウェブサイトです。

## 技術スタック

- Vue 3
- Vite
- HTML/CSS/JavaScript

## 開発環境のセットアップ

### 必要な環境
- Node.js
- npm

### インストール
```sh
npm install
```

### 開発サーバーの起動
```sh
npm run dev
```

### 本番ビルド
```sh
npm run build
```

## 機能

- レスポンシブデザイン
- スライドショー
- 料金表表示
- LINE予約システム
- Google Maps連携

## ライセンス

このプロジェクトは商用利用可能です。
